# План разработки

## Этапы

1. **Подготовка (завершён):** структура, документация и единый Hardhat 3
   Viem test stack.
2. **Контракты:** определить интерфейсы, реализовать STK и контракт
   подписки, затем провести review прав доступа и событий.
3. **Тесты:** написать Node.js/Viem тесты выпуска, обоих тарифов, всех
   вариантов продления, недостаточного баланса и истёкшего доступа.
4. **Локальное развёртывание:** добавить модуль Ignition и экспортировать
   адреса/ABI в `shared/`.
5. **Backend:** FastAPI, проверка wallet signature, чтение контракта через
   Web3.py и защищённый endpoint чата к Ollama.
6. **Frontend:** Vite-страница с MetaMask, балансом, подпиской, оплатой и
   чатом.
7. **Интеграция:** ручной end-to-end сценарий в локальной сети и screenshots.

## Контрольные точки

| Точка | Критерий результата |
| --- | --- |
| Среда | Node 22.13+, npm 11.3+, `npx hardhat --help` выполняется. |
| Контракты | `npm run compile` завершён без ошибок. |
| Подписки | `npm test` проверяет обе цены и правила накопления периода. |
| Backend | Истёкшая подписка не получает доступ к Ollama. |
| E2E | Пользователь получает STK, покупает тариф и отправляет AI-запрос. |

## Порядок реализации

К следующему этапу переходить только после подтверждения результата текущего:
сначала контракты и тесты, затем локальное развёртывание, после — backend и
frontend. Это предотвращает реализацию UI вокруг непроверенного контракта.
