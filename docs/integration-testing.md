# Интеграционное тестирование AI Token Access

Дата: 08.11.2026. Все проверки выполнены только в локальной Hardhat Network
`31337`; реальные активы и публичные сети не использовались. Фактический
браузерный кошелёк — Trust Wallet Browser Extension (EIP-6963/EIP-1193), не
MetaMask.

## Итог

Integration-runner выполнил 32 assertions без ошибок. Регрессия: Hardhat
29/29, backend 30/30, frontend 6/6; Vite build успешна. Первичный отдельный
`npm run compile` получил временный Windows `EPERM` при переносе build-info,
но последующий `npm test` успешно скомпилировал оба Solidity-файла и выполнил
все 29 контрактных тестов. Это блокировка файлов среды, не ошибка Solidity.

Критических ошибок не обнаружено. Проект готов к локальной демонстрации;
перед демонстрацией необходимо держать запущенными Hardhat node, FastAPI,
Ollama и Vite. Годовая покупка через Trust Wallet вручную не выполнялась:
на демонстрационном кошельке после месячной покупки 200 STK, а годовой тариф
проверен реальным автоматическим integration-runner.

Исправления тестовой инфраструктуры: добавлен snapshot/revert, чтобы тест
истечения не оставлял сдвинутое время; перед повторным запуском также
восстанавливается ETH тестового account с проверкой insufficient-gas. После
исправления повторный integration-runner прошёл 32/32.

Integration-runner создаёт Hardhat snapshot и после успешного прогона откатывает
все собственные тестовые платежи и изменение времени. Для текущего прогона,
выполненного до добавления отката, время локальной сети уже было сдвинуто при
проверке истечения; перед следующей демонстрацией среду следует развернуть
заново и повторно выдать демонстрационному Trust Wallet 300 STK и 1 ETH.
