# Сценарий демонстрации

1. `npm run node` — RPC 8545. Скриншот 01.
2. `npm run local:deploy` — STK и subscription addresses.
3. `ollama serve` с `OLLAMA_MODEL=qwen3:4b-instruct` — локальная модель.
4. Uvicorn на 127.0.0.1:8000 — `/health` возвращает ok.
5. `Set-Location frontend; npm run dev` — UI 5173.
6. В Trust Wallet выбрать Hardhat Local и подключить кошелёк; подтвердить SIWE. Скриншот 06.
7. Выдать 300 STK/ETH fund scripts при необходимости. Скриншот 03.
8. Показать обе карточки. Скриншоты 04–05.
9. Купить MONTHLY: вручную подтвердить approve и purchase. Скриншот 07.
10. Показать активный срок и отправить вопрос Qwen. Скриншоты 09, 11.
11. Купить MONTHLY повторно, показать добавленный срок. Скриншот 10.
12. Другому test-account выдать 2500 STK, купить YEARLY. Скриншот 08.
13. Показать 365-day срок и ответ Qwen.
14. Для аккаунта без подписки показать заблокированный чат/403 API.
15. Запустить `npm test` и pytest. Скриншоты 12–13.

Все действия — только локальная сеть и тестовые средства; не используйте реальный кошелёк.
